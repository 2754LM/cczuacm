## ✨ 关于我们

我们是常州大学 ACM 集训队，由对算法竞赛充满热情的同学组成，多次代表学校出征 ICPC、CCPC 等程序设计竞赛。队内提供系统的算法学习资料、训练环境与参赛机会，欢迎每一位对算法感兴趣的同学加入。

## 🚀 官网功能

- 入门指南：从零开始接触算法竞赛
- 集训队简介 / 加入方式 / 队员去向
- 往年获奖成绩一览
- 比赛题解与算法讨论

## 🛠️ 技术栈

- 文档框架：**VitePress**
- 公式渲染：KaTeX
- 数据统计：Umami
- 部署：GitHub Pages + 自定义域名 `cczuacm.cn`

## 🧑‍💻 本地开发

```bash
npm install       # 安装依赖
npm run docs:dev  # 本地预览
npm run docs:build # 构建
```

详细文档位于 `docs/` 目录。
